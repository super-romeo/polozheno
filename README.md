## Числитель и знаменатель замера

**Числитель** — целевые заявки из панели ответов формы, минус свои тестовые.
**Знаменатель** — клики из кабинета Директа, не визиты Метрики.
Цель `lead_submit` системно недосчитывает: Яндекс.Форма не перебрасывает на
`thanks.html` сама, а показывает экран с кнопкой «Перейти на сайт».

«Пока не знаю, нужна консультация» в числитель НЕ идёт.

## Чего здесь намеренно нет

Файла `CNAME`. Он кладётся только после того, как DNS-запись проверена
запросом и резолвится. При неработающем DNS и идущих показах он гасит живой
адрес — так уже едва не случилось со смоуком ОБ (ход-027). Запись
`polozheno.veridok.ru → super-romeo.github.io` в REG.RU не поставлена:
форма входа регистратора защищена анти-ботом, обходить запрещено.
